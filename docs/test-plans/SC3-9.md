テストは SC3-8 と同じテスト用 DB（Alembic で作ったもの）に、ダミーデータ（`app.seed`）を入れた状態で流す。テストごとに取り消す。API は FastAPI の TestClient で呼ぶ。

## 作る API

| API | 呼べる人 | 他社・存在しない |
| --- | --- | --- |
| `GET /api/ecus` | サプライヤの全員（自社の ECU だけ） | 他社の ECU は出ない。メーカーは 403 |
| `GET /api/ecus/{ecu_id}/assessment` | サプライヤの全員（自社の ECU だけ） | 404（他社も存在しない番号も同じ応答） |
| `PUT /api/ecus/{ecu_id}/draft` | 入力者だけ（自社の ECU だけ）。ほかの役割は 403 | 404。DB は変わらない |

仮の本人確認：ヘッダー `X-Dev-User-Id`。設定 `DEV_AUTH_ENABLED` が true のときだけ動く（既定は false。false なら 401）。Day 6 に JWT へ差し替える。

下書き保存：作業中の版が下書き → 書き換え。差し戻し → 下書きに戻して書き換え。承認待ち → 409。作業中がなく承認済みだけ → 新しい版（番号＋1）の下書き（承認済みの版は書き換えない）。版なし → 版1の下書き。送らなかった項目は前の値のまま（新しい版では、前の承認済みの版の値を写す）。保存は監査ログに残す。
