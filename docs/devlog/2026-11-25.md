## 学び

- 消し残しの検査やルートの網羅の検査は、「空だから通った」が起きやすい。期待する集合と突き合わせ、空なら落ちる形にする
  - 車載でいう、診断の網羅のテストで「対象が 0 件なら合格」にしないのと同じ
- 期限のあるトークンは、遅れて届く古い応答に注意が要る。送ったトークンと今のトークンを比べて捨てる
  - CAN の古いフレーム（カウンタの巻き戻り）を捨てるのと同じ考え方
- 最後の回のレビューの直しは、1つずつ戻して落ちるテストを確かめると、テストが本当に直しを守っているかが分かる
- パスワードの決まりは NIST SP 800-63B 第4版が基準になる
  - 15文字以上
  - 文字の種類の決まりは課さない
  - 定期的な変更は求めない
  - よく使われるパスワードの一覧と照合する
  - 人に複雑さを強いるより、長さと弱い値の排除が効く
