AWS の練習の手順です。区分：$ARGUMENTS

クレジットや請求の画面は、Claude からは見ない（`aws account`・`aws freetier` などは deny）。画面での確認はオーナーにお願いし、結果の数字だけを教えてもらう。手順の画面の名前は、実行の前に AWS の公式ドキュメントで確かめて、出典を添える。

## 開始

1. オーナーにお願いする：「請求とコスト管理」で**残りのクレジット**と、無料プランの**残り日数**を見て、数字を教えてもらう。devlog に書く
2. `aws sts get-caller-identity` が、練習用の IAM ユーザーで成功することを確かめる（ルートユーザーなら止める）。リージョンが東京（ap-northeast-1）か確かめる
3. 今日作るリソースを、`terraform -chdir=infra/<構成> plan -out=tmp/plan.bin`（裏で動かす）で一覧にし、次の表をオーナーに出す
   - リソースの種類・数・大きさ（インスタンスの種類）
   - **動いている時間だけ課金されるもの**（ALB、RDS、EC2、パブリック IPv4 アドレス）と、1時間あたりの見込み（公式の料金ページで確かめ、出典を添える。推測なら推測と書く）
   - 費用ゼロのガードレール（CLAUDE.md）に反するものがないこと。サブエージェント `aws-cost-reviewer` にも見てもらう
4. オーナーの承認をもらってから `terraform apply tmp/plan.bin`（確認の画面が出る。裏で動かす）。作り始めた時刻を devlog に書く

## 終了（その日の作業が終わったら、必ず）

1. `terraform -chdir=infra/<構成> destroy`（確認の画面が出る。裏で動かす）。終わったら `terraform -chdir=infra/<構成> state list` が空であることを確かめる
2. Terraform の外に残りやすいものを確かめる（読むだけのコマンド）：EC2 のインスタンス、Elastic IP、ロードバランサー、RDS のインスタンスとスナップショット、NAT Gateway、CloudWatch Logs のロググループ（Lambda が自動で作る）、S3 のバケット
3. オーナーにお願いする：「請求とコスト管理」で**その日の使用量**を見て、数字を教えてもらう。devlog の「AWS」の節に、作った時刻・消した時刻・使用量・残りのクレジットを書く
4. 消し残しがあれば、オーナーに場所を伝え、承認をもらってから消す

## 月次（月に1回）

- オーナーにお願いする：Tag Editor で**全リージョン**の残りのリソースを見てもらう（東京以外に作っていないか）
- Budgets のアラートが有効か、無料プランのままか（有料プランに切り替えていないか）を確かめてもらう
